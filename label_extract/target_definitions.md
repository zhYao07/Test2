# 12 类目标定义与软分数说明（v3）

来源：主办方 [Knee Abnormality Detection AI Challenge Overview](https://www.kaggle.com/competitions/rsna-knee-abnormality-detection/discussion/733343)，2026-10-07 核对 Label Description 正文。以下为释义；报告抽取生成弱标签，不能替代影像共识金标。

| 类别 | 阳性目标 | 阴性及注意事项 |
|---|---|---|
| ACL | 前交叉韧带高级别部分撕裂（超过 50% 纤维中断）或全层撕裂 | 轻微信号变化、退变、无中断的增厚不满足；不明确的部分撕裂程度作为软估计的不确定因素 |
| MCL | 内侧副韧带高级别部分或完全急性撕裂，纤维中断及韧带内外水肿 | 低级别扭伤、慢性或陈旧应力改变不满足 |
| Medial Meniscus | 内侧半月板信号明确到达表面且至少两幅图像可见，或截断、缩小、移位碎片等形态异常 | 未达表面的内部退变不满足；报告明确诊断撕裂可作为文本阳性依据，不虚构图像观察 |
| Lateral Meniscus | 与内侧相同标准，作用于外侧半月板 | 不能跨侧推断；仅手术史或术后改变不足以建立当前撕裂 |
| Medial OA | 内侧胫股间室约 1 cm 或更大范围的高级别软骨缺损，超过 50% 软骨厚度 | 可伴软骨下改变；骨赘、水肿或泛称 OA 不直接确证深度和范围，但可结合全文形成部分证据软估计，记录缺项 |
| Lateral OA | 与内侧 OA 相同标准，作用于外侧胫股间室 | 独立判定间室、深度及范围 |
| PF OA | 与内侧 OA 相同标准，作用于髌骨或股骨滑车的髌股间室 | 独立判定间室、深度及范围 |
| Effusion | 中量或大量关节液使关节腔扩张 | 轻微/少量为亚阈值；量级及扩张证据影响软分数与证据强度，不编造扩张描述 |
| Synovitis | 关节滑膜内衬炎症和增厚 | 积液、脂肪垫水肿不自动等于滑膜炎；明确滑膜炎诊断可作为文本证据 |
| Baker's | 膝后典型位置的中量或大量 Baker/腘窝囊肿液性集合 | 小囊肿亚阈值，其他滑囊或半月板囊肿不混入；程度不清时记录部分证据 |
| Contusion | 撞击导致的骨髓水肿样信号，无明确骨折线 | 单纯不明原因骨髓水肿、退变性软骨下水肿不自动阳性；明确骨挫伤诊断可作为证据，不虚构骨折线排除 |
| Fracture | 急性皮质中断或骨折线 | 陈旧骨折、手术 microfracture 不满足；明确急性骨折诊断支持高软分数，不虚构线的观察 |

主办方在影像标注中将模糊或临界所见判阴性。这里输出连续软估计：必要细节缺失、疑似或矛盾可以形成部分/冲突证据软分数，单独记录缺项并降低训练权重；未提及或无任何有用依据才留空并屏蔽。不将信息缺失等同于已确认阴性，也不把推断写成已观察到的事实。

软分数是 LLM 对是否符合目标定义的未校准估计，不是经临床验证的概率。示例和规则不能消除报告与影像金标之间的差异。

## 跨病例统一证据口径

- OA 的目标是达到深度和范围条件的软骨损伤。明确低级别、minimal 或 <50% 厚度缺损支持低分，不能由骨赘或泛称 OA 改为高分。全层/高级别但未给范围，以及仅泛称 OA，保留软估计并记 PARTIAL。仅软骨信号正常属于部分阴性证据；明确软骨正常/无缺损可为 DIRECT。髌骨外侧面属于 PF OA。
- Effusion 的 minimal/trace/small/mild 是亚阈值，即使 report_status=PRESENT，目标分数仍应低。moderate 和 large 均支持较高估计，但缺关节腔/隐窝扩张描述时统一为 PARTIAL；不能只对 moderate 降权而对 large 当成条件完整。量级未说明也为 PARTIAL，记录量级和扩张缺失。
- 阳性缺少必要条件时用 PARTIAL，与分数高低独立。阴性若已明确排除一个必要条件，其他无关缺项不强制降权，例如明确 <50% 深度的软骨损伤不需要再知道范围才能支持低分。
- ACL 撕裂位置不代表纤维撕裂比例；未说明高级别/完全的撕裂为 PARTIAL。一级损伤、低级别扭伤或明确无撕裂不等于阳性。MCL 还需急性纤维中断依据。小量 Baker 囊肿也不能仅凭存在而高分。
- 旧 label.csv 和 labels_blend.csv 是对照用的软标签文件，不是真值；不以复现旧数值为目标。原始影像金标、报告事实、LLM 软估计保持各自来源，未提及不填 0 或 0.25。
