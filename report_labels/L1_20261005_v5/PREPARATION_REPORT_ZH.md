## 输入检查

- 4407 个唯一 UID，4407 份非空报告；原文最短 52、中位 977、最长 4743 字符。
- 4276 个完全相同原文组，4257 个保守规范化组；256 对近似重复候选仅供复核，不合并。
- 58 个有完整专家标签的病例单独保存，值不进入模型输入。抽样排除了所有含 gold UID 的规范化组。
- 180 份抽样：90 份语言/长度分层，90 份高风险；180 个不同规范化报告组。

- 语言是词典提示而非概率。独立来源审计发现 8 个语言提示偏差及若干 UNKNOWN 可辨识语言；不阻止多语言全文阅读。
- 一份试跑报告实际为肩部报告，见 non_knee_report_candidates.json。schema 1.1 增加整体报告部位，确认 OTHER/UNCLEAR 的全部膝关节目标屏蔽。病史中的其他部位不能据此排除整份膝关节报告。

## 模型与输出边界

使用官方 Codex CLI 0.160.0、精确 model slug gpt-6.1-sol、medium reasoning、HTTPS 传输和最多 3 个并发报告。每份调用 read-only/ephemeral，禁用工具，不读取专家标签。未复制或导出凭据。服务端未暴露不可变 snapshot，不能宣称已锁定模型权重；记录代码、prompt/schema、模型配置和数据指纹。

独立 Python 映射器把明确 YES/NO 映射到 0.95/0.05、weight=1、mask=1；证据不足软项 weight=0.25；未提及、关键错误、历史无当前评估和复核排除项 target 空、weight=0、mask=0。证据保留原文和偏移。软分数未校准。

试跑须完成 2160 个报告×类别的七维语义审计；审计者明确记录为独立模型文本复核，不能称为临床专家或影像金标审计。关键错误必须 MASK。否定范围不足时 class_absence_supported=null，映射 UNKNOWN 且 mask=0。放量门槛预先固定为至少 216 个保留有效监督项，膝关节已提及项及所有审计 FAIL 项错读率 ≤5%，每类 ≥20 个适用项时错读率 ≤10%；合法排除且无 FAIL 不计错读。通过后全量导出全部 UID 和每类 target/weight/mask，并单独报告文本质量及 58 例 gold 方向性 AUC。

36 项离线测试通过；假响应仅验证程序，不代表真实标签质量。本次仅完成报告提取阶段，不开展图像教师、共现或滑膜炎补全、MRI 训练。

旧版 V3 已完成 8 份报告后因局部否定映射缺陷停止，响应留作诊断，不复用为 V4 模型结果或审批。V4 对原始 train 和准备数据哈希核对一致，因此保留此前独立来源审计作为数据来源检查；类别提取审计重新开展。
